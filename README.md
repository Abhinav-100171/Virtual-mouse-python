Virtual Mouse Using Python

Project Overview

A computer vision project that allows users to control the mouse pointer using hand gestures captured through a webcam.

Features

- Real-time hand tracking
- Cursor movement using the index finger
- Left-click using a thumb and index finger gesture
- Webcam-based interaction

Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI

Installation

Install the dependencies:

pip install -r requirements.txt

Run the Project

python virtual_mouse.py

Press "Q" to close the webcam window.
